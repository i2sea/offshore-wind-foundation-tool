# 해상풍력발전기 기초 설계도구

해상풍력발전기 하부 기초의 형상을 입력하면 도면·3D 모델, 하중, 검토, 수량, 구조계산서를 함께 계산하는 웹 도구입니다. 형식은 대분류 **모노파일(단일 직경·테이퍼형)**, **자켓(3각·4각)**, **중력식(원추형·케이슨형)** 으로 나뉩니다. 개발 계획은 `docs/개발계획_기초형식확장.md`.

- 실행: `dist/foundation-tool.html` 하나를 브라우저(크롬·엣지)로 열면 됩니다. 인터넷 연결 필요(엑셀·3D 라이브러리 CDN).
- 기본 입력값은 일반 예시 형상·조건(가정)입니다. 현장 자료(터빈·지반·설계)는 도구에 넣지 않고 파일(.json)로 따로 관리해 "가져오기"로 불러옵니다.
- 단위: m, kN (별도 표기 제외)

## 구성

```
src/head.html    화면 구성·스타일
src/engine.js    형상·자중·부력·터빈·풍·파랑·조류·지진·하중조합·안정검토·부유 안정
src/member.js    부재설계(KDS 14 20)·배근 상세·철근재료표·최적 배근·부재설계+진동수 동시 수정·최적 제원
src/mono.js      모노파일: 형상·강관/TP 중량·풍·파랑·조류·지진·해저면 단면력·단면 응력(예비)·수량
src/jacket.js    자켓: 형상, 부재별 Morison 하중, 3D 골조 강성행렬 해석, NORSOK N-004 부재 검토, 말뚝 반력·지지력·p-y, 고유진동수
src/ui-jacket.js 자켓 화면: 입면·평면도, 3D, 탭 내용, 계산표, 주의·자동 수정
src/pile.js      지층·가정 지반, p-y 말뚝 해석(API 모래·점토, Reese 연암), 회전각, 근입, 축방향 지지력, 쉘 좌굴
src/ui.js        화면 동작(대분류·소분류 전환), 도면(SVG/DXF), 3D, 계산서(DOCX)·계산표(XLSX), 저장, 주의·자동 수정
src/ui-mono.js   모노파일 화면: 입면도·평면도, 3D, 탭 내용, 계산표, 주의·자동 수정
src/start.js     시작(저장된 입력 불러오기)
build.sh         src를 합쳐 dist/foundation-tool.html 생성 + 문법 확인
tests/validate.js 해석해·손계산 비교 (현장 자료 재현 검증은 저장소 밖 비공개 폴더)
```

## 사용

```sh
./build.sh              # dist/foundation-tool.html 생성
node tests/validate.js  # 계산 검증
```

claude.ai 아티팩트로 게시하면(권한: db, user, downloads) 설계 저장이 계정에 남습니다. 브라우저에서 파일을 직접 열거나 웹 서버(GitHub Pages 등)에 올리면 설계 저장은 그 브라우저에만 되고, 파일 받기는 일반 브라우저 다운로드로 됩니다.

## 기능

- 형식: 대분류 버튼(모노파일 / 자켓 / 중력식)을 누르면 입력란과 탭이 바뀌고, 소분류 버튼은 같은 탭에서 모양만 바꿈
  - 중력식: 원추형(저판+하부 원통+원추+원형 기둥), 케이슨형(평저 케이슨+방사 격벽+원형/육각 샤프트)
  - 모노파일: 단일 직경, 테이퍼형(하부 → 상부 직경, 테이퍼 구간 표고). 두께 3구간, TP(그라우트/볼트 연결), 설치 방식(항타/드릴드/항타-천공-항타), 세굴방지공 유무
  - 자켓: 3각·4각, X 브레이스(칸 수·칸 높이 비), 경사 다리, 중간 수평재 선택, TP, 다리당 연직 항타 말뚝
- 중력식 탭: 일반도, 배근도(A3), 3D 모델, 하중, 안정검토, 부재설계, 부유 안정, 자중·부력, 수량, 응력분포도, 구조계산서
- 자켓 탭: 일반도(입면·평면), 3D 모델, 하중(부재별 Morison·해저면 합력·다리 반력), 자중·부력, 부재 검토(NORSOK N-004), 말뚝·지반, 수량, 구조계산서
- 모노파일 탭: 일반도(입면·평면), 3D 모델, 하중(해저면 단면력), 자중·부력, 강관 단면(D/t·해저면 응력 예비), 말뚝 해석(지층 표·p-y·회전각·근입·축방향 지지력), 수량(해역이용협의 점용 면적·굴착량), 구조계산서
- 버튼: 형식별 최적 제원 찾기, 부재설계 + 진동수 동시 자동 수정(중력식: 저판·벽체는 철근 → 두께 → 저판 직경, 기둥은 강성을 덜 키우는 순서로 철근 H35@100까지 → f_ck 45~60 MPa → 벽두께(키우고, 앞선 수정으로 두꺼워졌으면 0.4 m까지 줄임 — 하한 가정) → 외경을 soft-stiff 허용 구간 안에서만 조정, 허용 구간은 추정 회전수 기준 가정), 부재설계만 자동 수정(철근 → 두께 → 그래도 N.G면 기둥 외경 +0.2 m·저판 직경 +1.0 m씩, 상한 기둥 15 m·저판 60 m 가정, 진동수 변화 함께 표시), 철근 + 두께까지만, 철근만 (두께 상한: 저판·하부 슬래브 ≤ 3.0 m, 벽체·원추 ≤ 1.0 m, 기둥 벽두께 ≤ 0.4 × 기둥 반경 — 상한은 실무 범위로 둔 가정값이며 넘으면 외경 등 제원 변경을 안내), 주의 사항 자동 수정
- 파일 받기: claude.ai 안에서는 다운로드 기능, 밖(사내 PC·웹 서버)에서는 일반 브라우저 다운로드
- 일반도: 정면 단면도·평면도(치수 직접 수정) + A3 일반도 도면(흑백, 단면도·평면도·주기·설계 조건·검토 결과 요약·주요 수량·표제란, 입력값과 계산 결과로 자동 작성). 보강 링은 단면도에 번호(①②…)와 제원 목록, 평면도에 숨은선 원과 번호로 표시
- 출력: CAD(.zip: 일반도 A3·배근도 A3·일반도·단면도·평면도 DXF), 구조계산서(.docx), 계산표(.xlsx)

## 적용 기준과 방법

| 항목 | 적용 방법 | 근거·비고 |
|---|---|---|
| 체적 | 부재별 정식 + 0.005 m 간격 수치적분, 겹침 공제 | |
| 육각 샤프트 | 면적이 같은 원으로 환산(부력·파랑), 도면은 맞변 폭 | |
| 속채움·부력 | 외곽 안 빈 공간만 속채움(콘크리트 체적 제외), 부력은 잠긴 외곽 체적 | |
| 터빈 | 기본 목록은 공개 기준 터빈(DTU 10MW·IEA 15MW 제원·타워 치수, 하중표 없음)뿐. 제작사·사업 터빈 자료(제원·하중표)는 도구에 넣지 않고 터빈 파일(.json, `{app:"gbs-tool-turbine",turbines:[…]}`)로 따로 관리 — "터빈 파일 가져오기"로 불러오면 브라우저 터빈 목록에 남음, "선택 터빈 파일로 저장"·"추가한 터빈 모두 저장"으로 내보냄. 사용자 추가·편집, 연직축 x/z 지정. 설계에 저장된 터빈이 목록에 없으면 주의 표시 | DTU 10MW 타워 길이 105.63 m는 육상 타워를 인터페이스 MSL+10 m에 맞춘 가정. 타워 제원·기준 진동수가 없는 터빈은 진동수를 계산하지 않고 비교용 입력값(0 = 없음)을 씀 |
| 풍하중 | DNV-RP-C205 Frøya, C = 5.73e-2·√(1+0.148U₀) | |
| 항력계수 | 표면 거칠기 k와 높이별 직경 D로 Δ=k/D → 0.65 / (29+4log₁₀Δ)/20 / 1.05, 레이놀즈수 확인 | 원문 대조 필요 |
| 파랑하중 | MacCamy-Fuchs 관성력 + 항력, 위상 탐색 | MacCamy-Fuchs 해석해 재현 |
| 조류 | 상시(대조기 최강) / 극치(50년 + 바람 해류 0.015U₀) 분리, 1/7승·직선 분포 | 유속 1.0 m/s 가정 |
| 지진 | k_h = 지반 분류별 PGA × 진도 환산계수, 동수압은 배제수 부가질량 | 지반 분류는 지반조사로 확정 |
| 하중조합 | LC1 상시(SLS), LC2 폭풍(ULS, 설계조위), LC3 폭풍(ULS, 저조위), LC4 지진(SLS) | |
| 안정검토 | 전도 V′R/M, 활동 μV′/H, 편심 e ≤ D/8(상시), 유효면적법(극한), 지지력, 기울기 0.25° | FS·μ·q_a·유효접지율은 기본값 |
| 부재설계 | KDS 14 20 강도설계, 해양 피복 75 mm, 저판(1방향 양단고정), 벽체·원추(정지토압 원주 인장 + 하단 휨), 기둥 하단(원형 중공 P-M, 띠철근) | 피로·프리스트레스 미포함 |
| 응력분포도 | ① 기둥 높이별 N·V·M·연단 응력 σ = N/A ± M/Z (사용하중, LC1~LC4, 단면 위쪽 하중만: 터빈 + 풍·파랑(단면별 최대 위상)·조류·지진, 자중은 수중부 수중단위중량, 기둥 속채움 제외) ② 저판 하면 지반반력 분포(핵 안 사다리꼴, 핵 밖 유효 면적 균등 q_eff) ③ 저판·벽체·원추 휨모멘트 분포(계수하중, 그래프마다 위치 안내 그림(칠한 부재·x 방향), 케이슨 저판은 L = min(반경 방향, 격벽 간격) 표시, 저판 양단고정 보, 벽체·원추 M(x) = M_u e^{−βx}(cos βx − sin βx)) | 쉘 경계 휨 분포는 근사(가정). 육각 기둥은 같은 면적 등가 원형 |
| 보강 링 배치 | 자동(기본): ① 기둥 하단 링 — 기둥 내면에 붙여 저판 상면에서 시작, 외경 = 기둥 내경, 두께 = 기둥 벽두께 ② 벽체 접합부 링 — 원통(외벽) 내면에 붙여 저판 상면에서 시작, 외경 = 벽체 내경, 두께 = max(0.5, 벽두께). 높이 = 1.5 × 정착길이 40d(기둥 주철근·벽체 연직철근) → 0.5 m 올림, 최소 1.0 m. "직접 입력"으로 바꾸면 자동값이 표로 옮겨져 고칠 수 있음. 링을 저장한 예전 설계 파일은 직접 입력으로 열림 | 배치·크기 규칙은 가정 (강도 검토 아님) |
| 보강 링 배근 | 강도 부재로 보지 않고 최소철근(배력, ρ 0.0018 양면)으로 배근: 원주(내·외면), 연직(내·외면, 저판까지 곧게 닿는 면은 아래 링을 지나 저판 하부철근 위까지 내려 갈고리 40d — 시공 시 저판 철근에 걸어 세움, 아래가 비어 있는 면은 링 안에서 끝나고 옆 연결철근으로 고정), 옆에 닿는 기둥·벽체와 수평 연결철근(0.3 m 격자, 양쪽 40d). 아래·옆에 닿는 부재가 없으면 "공중에 떠 있음", 일부만 얹히면 주의 표시. 배근도·철근재료표에 G11·G12·G13… | 연결철근 간격·정착길이는 가정 |
| 부유 안정 | 흘수, GM = KB + BM − KG − 자유수면 보정(격벽별), 예인 높이별 표 | |
| 모노파일 형상 | 높이(DL)별 외경: 단일 직경 또는 테이퍼 구간 직선 변화, 두께 3구간. TP 그라우트 연결 길이 = 1.5 × 말뚝 상단 직경, TP 상단 = 터빈 인터페이스 | 연결 길이 1.5D는 가정 기준 |
| 모노파일 중량 | 강관 π·t(D−t) 수치적분(0.05 m), TP·그라우트 정식, 2차 부재 1,500 kN | 2차 부재 중량 가정 |
| 모노파일 파랑 | 높이별 직경(해양생물 포함)으로 MacCamy-Fuchs 관성 + 항력, D/L > 0.2 회절 / 이하 Morison 영역 표시(작은 ka에서 C_M → 2.0) | 해석해 ρπa²C_Mω²H/2k 재현 |
| 모노파일 풍·조류·지진 | 풍: 설계조위~TP 상단 Frøya. 조류: 중력식과 같은 분포. 지진: k_h × (강관·TP·터빈·관내 해수 + 배제수 부가질량) | 해양생물 50 mm(MSL+2 m 아래) 가정 |
| 세굴 | 세굴방지공 있으면 세굴 없음, 없으면 S = 1.3D (DNV 평형 세굴 경험값)만큼 해저면을 내려 단면력 계산 | 가정값 |
| 모노파일 하중조합 | 해저면 기준 LC1 상시(SLS), LC2 폭풍(ULS, 환경하중 × 1.35), LC3 지진. 터빈 M + H·(y_if − y_ML) | |
| 강관 단면 (예비) | 해저면 σ = V/A + M/Z (부식 여유 공제) ≤ f_y/γ_M, D/t ≤ 120 | 120은 실무 범위 가정. 쉘 좌굴·p-y는 다음 단계 |
| 지층 · 가정 지반 | 지층 표(모래 φ, 점토 Su 상·하단, 암반 q_u·E_m·RQD, γ′). 지반조사 전에는 가정 지반 4종(연안 일반·모래·점토·얕은 암반) 중 선택, 표를 고치거나 엑셀 10열을 붙여넣으면 '직접 입력'으로 바뀜 | 가정 지반은 임시값 |
