# 개발 계획 — 기초 형식 확장 (자켓·모노파일)

상태: 1단계(형식 구조)·2단계(모노파일 형상·도면·하중) 완료, 3단계는 가정 지반으로 p-y·회전각·근입·축방향·쉘 좌굴까지 완료 (2026-11-10). 남은 3단계: 최적화. 자켓 4~5단계 대부분 완료(2026-11-10), 남은 것: 접합부 펀칭(NORSOK N-004), K 브레이스, 말뚝 유연성, 석션버킷, 최적화. 지반조사 자료가 오면 지층 표만 바꾸면 됨.

## 0. 형식 구조

| 대분류 | 소분류 | 계산 방식 | 상태 |
|---|---|---|---|
| 중력식 | 원추형, 케이슨형 | 강체 안정검토(전도·활동·지지력) + 철근콘크리트 부재설계 | 완료 |
| 자켓 | 3각, 4각 | 3D 골조해석 + 강관 부재·접합부 검토 + 말뚝 | 형상·하중·골조해석·부재·말뚝·진동수 완료, 접합부·석션버킷·최적화 예정 |
| 모노파일 | 단일 직경, 테이퍼형 | 지반 스프링 위 보 해석(p-y) + 강관 쉘 검토 | 형상·하중·수량 완료, 해석 예정 |

- 대분류를 바꾸면 입력란·탭 구성이 바뀌고, 소분류를 바꾸면 같은 탭에서 모양만 바뀐다.
- 고정 방식(항타 / 드릴드 / 석션버킷)은 소분류가 아니라 입력 옵션으로 둔다.
- 공통 유지: 터빈, 설치 위치·수위, 풍·파랑·조류·지진 조건, 저장, 주의·자동 수정, 최적화 틀, 출력.

화면:
```
형식   [ 중력식 ] [ 자켓 ] [ 모노파일 ]
       └ 중력식:   [ 원추형 ] [ 케이슨형 ]        최적화
       └ 자켓:     [ 3각 ] [ 4각 ]                최적화
       └ 모노파일: [ 단일 직경 ] [ 테이퍼형 ]     최적화
```

## 1. 공통으로 재사용
- 터빈 목록·하중표(연직축 지정), 인터페이스 높이 처리
- Frøya 풍속, 조류 분포(조석류 + 바람 해류), 항력계수(Δ = k/D), 지진계수(지반 분류)
- 주의·팁·자동 수정, 최적화 탐색 틀, 설계 저장, DOCX·XLSX·DXF 출력

## 2. 자켓

### 입력
- 3각 / 4각, 다리 간격(상단·하단), 높이, 트랜지션피스 높이·형식·중량
- 브레이싱: X형 / K형, 단 수, 각 단 높이
- 부재 규격: 다리·브레이스 외경·두께(구간별)
- 말뚝: 다리당 개수, 직경·두께, 설치 방식(항타 / 드릴드), 그라우트 슬리브 길이
- 재료: 강재 등급(S355 등), 그라우트 강도, 부식 여유두께, 해양생물 부착 두께

### 하중
- 부재별 Morison(관성 + 항력), 경사 부재는 수직 성분, 파봉 위상 탐색
- 물 위 풍하중, 물 아래 조류, 자중·부력(강재·그라우트·해양생물·부재 안 물), 터빈 하중(TP 상단), 지진(부가질량)

### 해석·검토
- 3D 골조해석(강성행렬법): 절점 변위, 부재력, 말뚝 반력. 말뚝 지지는 고정 → 지반 스프링으로 교체 가능
- 고유진동수(타워 포함 간이 모델) vs 1P·3P
- 강관 부재: 축력 + 휨 조합, 국부 좌굴(D/t), 전체 좌굴(유효길이)
- 접합부: K·X·T 펀칭 전단 (기준 결정 필요: API RP 2A / ISO 19902 / DNV)
- 말뚝: 압축·인발 지지력, 드릴드는 소켓 길이·그라우트-암반 부착·강관-그라우트 부착, 항타는 API 주면마찰 + 선단, 수평 저항
- 그라우트 연결부: 슬리브 길이, 부착 강도
- 피로: 1차 제외, 항목만 표시

### 최적화
- 다리 간격·높이, 부재 외경·두께(강재 중량 최소), 말뚝 근입·소켓 길이

### 출력
- 입면도(2면)·평면도·부재 규격표·말뚝 상세, 3D, 부재력도, 강재·그라우트·천공 길이·방식 면적 수량

## 3. 모노파일

### 입력
- 단일 직경 / 테이퍼형(상부 직경 → 하부 직경, 테이퍼 구간 높이)
- 구간별 두께 분포, 근입깊이, 강재 등급, 부식 여유두께, 해양생물
- 트랜지션피스: 그라우트 연결 / 볼트(플랜지) 연결, TP 길이·중량
- 설치 방식: 항타 / 드릴드(암반 소켓) / 항타-천공-항타
- 세굴: 세굴 깊이(직접 입력 또는 1.3D 등 경험식), 세굴방지공 유무·범위·두께

### 하중
- 파랑: 대구경(D/L > 0.2)이면 MacCamy-Fuchs 회절, 작으면 Morison — 직경으로 자동 판정 (중력식 엔진 재사용)
- 풍(물 위 TP), 조류, 터빈 하중(TP 상단), 자중·부력, 지진

### 해석·검토
- 지반 스프링 위 보 해석: 깊이별 p-y(모래·점토 API 곡선, 암반은 암반 p-y), 축방향 t-z·Q-z
- 말뚝 머리 변위·회전: 사용 하중 시 해저면 회전각 기준(예: 0.25°, 시공 오차 포함 0.5°) — 기준값 확인 필요
- 영구 기울기(누적 회전) 항목은 표시만
- 강관 쉘: 휨 + 축력 응력, 국부 좌굴(D/t), 원주 좌굴
- 축방향 지지력, 근입깊이(소요 vs 입력)
- 고유진동수: 지반 강성 포함, 1P·3P 비교
- 드릴드 모노파일: 암반 소켓 길이, 그라우트 부착
- 피로·항타 관입성(drivability): 1차 제외, 항목만 표시

### 최적화
- 직경, 두께 분포, 근입깊이 → 강재 중량 최소 (회전각·좌굴·진동수 만족)

### 출력
- 입면도(두께 분포 표시), 깊이별 변위·모멘트·지반반력 그래프, 3D
- 수량: 강재 중량, TP 중량, 그라우트량, 세굴방지공(사석) 체적·면적
- 해역이용협의용 산출: 점용 면적(세굴방지공 포함), 굴착·천공량 — 이전 모노파일 D11 m 굴착량 산출 방식과 맞춤

## 4. 형식 비교 탭
- 같은 터빈·수심·파랑 조건에서 대분류별 대표안을 나란히: 주재료(콘크리트 / 강재) 수량, 기초 점용 면적, 시공 방법(예인·크레인·항타·천공), 주요 검토 여유율, 공사비 항목(단가 입력 시)

## 5. 필요한 자료

| 자료 | 쓰이는 곳 | 없을 때 |
|---|---|---|
| 10MW급 터빈 하중표 (타워 하단) | 전체 | 터빈 파일 가져오기 또는 사용자 입력 |
| 지반조사 (지층, 암반 일축압축강도, N값, 비배수 전단강도) | 자켓 말뚝, 모노파일 p-y | 암반 가정값으로 틀만 구성 |
| 파랑·조류 설계값 | 하중 | 예시값(가정) |
| 적용 기준 결정 (API / ISO / DNV) | 강관·접합부·말뚝 | 협의 필요 |
| 강재 등급, 부식 여유두께 | 부재 | S355, 가정값 |
| 세굴 자료 | 모노파일 | 경험식 |

## 6. 단계

1. 형식 구조 개편(대분류·소분류 버튼, 대분류별 입력·탭 전환) — 중력식 기능은 그대로 유지
2. 모노파일 1단계: 형상·일반도·3D·중량, 하중(기존 파랑 엔진 재사용)
3. 모노파일 2단계: p-y 보 해석, 회전각·쉘 좌굴·진동수, 최적화, 수량(해역이용협의 산출 포함)
4. 자켓 1단계: 형상·일반도·3D·중량, 부재별 Morison 하중
5. 자켓 2단계: 골조해석, 부재·접합부 검토, 진동수
6. 자켓 3단계: 말뚝, 최적화, 도면·계산서
7. 형식 비교 탭

모노파일을 자켓보다 먼저 두는 이유: 중력식의 원통 파랑 엔진(MacCamy-Fuchs)을 거의 그대로 쓸 수 있고, 해석이 1차원 보라서 자켓의 3D 골조해석보다 단순하다.
